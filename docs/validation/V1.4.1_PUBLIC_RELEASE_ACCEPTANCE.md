## 4. Physical target-PC acceptance (BLOCKING for stable public release)

Run on the final installed candidate, not an earlier portable build:

- [ ] Confirm Windows x64 version/build, native Npcap version, NIC driver, adapter name/type (sanitized), receive-only TAP/SPAN topology, installer SHA256, exact application assembly version.
- [ ] Confirm actual ASIX/other physical adapter enumerates without a fabricated fallback; start/stop/restart capture and uninstall/upgrade/repair on target Windows.

## 5. Publication control

- Main-branch PR merge only after automated checks.
- Public release workflow manual dispatch must explicitly confirm current **field_acceptance_verified**, and refuses non-main source; tag pushes **cannot automatically publish**.
- Stable GitHub release must include the Inno Setup installer as primary, portable ZIP as optional, SHA256SUMS, manifest and current release notes.
- Until all gates close: distribute an Actions **candidate** for testing, but do not tag/publish it as certified, calibrated, or generally interoperable.
